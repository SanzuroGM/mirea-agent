# mirea-agent

Материалы РТУ МИРЭА и инструкция для ИИ-агента, который помогает
студенту с учебными работами: ДР, лабораторными, практическими,
курсовыми, статьями и Jupyter-тетрадями.

Репозиторий состоит из двух частей:

- **`AGENT_GUIDE.md`** - инструкция для нейросети. В ней описано, где
  лежит каждый файл, как его прочитать и каким правилам следовать.
- **Папки дисциплин** - лекции, методички, шаблоны титульных листов,
  списки литературы и датасеты.

Гайд не пересказывает материалы. Он отправляет агента к нужному файлу,
поэтому при обновлении методички переписывать инструкцию не нужно.

---

## Быстрый старт

1. Откройте [`AGENT_GUIDE.md`](AGENT_GUIDE.md) и скопируйте его целиком
   в чат с нейросетью (LMArena, ChatGPT, Claude, DeepSeek и другие).
   Можно приложить файлом.
2. Напишите задачу обычными словами:

   > Сделай курсовую по стандартизации и метрологии, тема 2, вариант 5.

3. Агент сам:
   - определит тип работы и выведет его первой строкой, например
     `[ТИП: coursework]`;
   - найдёт в репозитории методичку и шаблоны;
   - одним сообщением спросит недостающее: ФИО, группу, преподавателя,
     исходные данные;
   - выполнит работу по методичке и оформит её по требованиям кафедры;
   - проверит текст по чек-листу и перечислит, какие файлы использовал
     и что нужно проверить вам.

### Если у нейросети нет доступа к GitHub

Агент назовёт точный путь к нужному файлу и попросит его приложить.
Скачайте файл из репозитория и отправьте в чат. Чтобы сэкономить шаг,
сразу прикладывайте файлы по вашей задаче:

| Задача | Что приложить |
|---|---|
| Курсовая по СиМ | `СиМ_Курсовая работа_Методические рекомендации.pdf`, оба титула из раздела ниже, своё задание с исходными данными |
| Практическая работа | `Title page - Практчиеская работа.docx`, задание преподавателя, лекции по теме |
| Тетрадь по ИИ | `Rules - Правила выполнения тетради пользователя.md`, рабочую тетрадь, нужный `.csv` |
| ДР по электротехнике | варианты, методичку и образец ДР (в репозитории их пока нет) |

## Что умеет агент

| Тип | Код | Что важно знать |
|---|---|---|
| Домашняя работа | `dr` | Порядок расчёта цепи задан (Кирхгоф, МКТ, МУП, МЭГ), но варианты и методичку нужно приложить |
| Лабораторная | `lab` | Методичку к лабораторной нужно приложить, экспериментальные данные агент не выдумывает |
| Практическая работа | `pr` | Есть шаблон титула |
| Отчёт по практике | `practice` | Шаблона нет, нужны требования кафедры |
| Курсовая | `coursework` | Для СиМ всё есть в репозитории: темы, расчёт, оформление, титулы, заявления |
| Статья, обзор, реферат | `article` | От 20 источников не старше 5 лет, приоритет ВАК К1, Scopus, WoS, проверка DOI |
| Jupyter-тетрадь | `notebook` | Ответ только в виде `.ipynb`, строго по стилю рабочей тетради |
| Объяснение лекции, подготовка | `study` | Ответ по лекциям с указанием файла |

## Основные правила, которые соблюдает агент

**Порядок приоритета.** Ваше указание в запросе важнее методички,
методичка важнее шаблона, а шаблон важнее общих правил гайда. Если
методичка противоречит гайду, агент следует методичке и сообщает об
этом.

**Ничего не выдумывает.** Источники, авторы, DOI, годы, исходные данные
и номера вариантов берутся только из ваших материалов или из
проверяемых баз. Непроверенный источник помечается «требуется
верификация».

**Титул только из шаблона.** Агент заполняет поля в шаблоне, а не
набирает титул по памяти. Данные из образцов (Иванов И.И., вариант 9)
в вашу работу не попадают.

**Оформление по умолчанию** взято из методички кафедры метрологии и
стандартизации:

- А4, поля: левое 30 мм, правое 10 мм, верхнее и нижнее 20 мм;
- Times New Roman 14 pt, интервал 1,5, абзацный отступ 1,25 см,
  выравнивание по ширине;
- номера страниц внизу по центру, на титуле номер не ставится;
- заголовки прописными полужирными по центру, без точки в конце;
- подписи: «Рисунок 1.1 – Название» под рисунком,
  «Таблица 1.1 – Название» над таблицей;
- ссылки на литературу в квадратных скобках: [1].

**Стиль текста:**

- научный и безличный, без «я», «мы», «важно отметить», «в современном
  мире», «является», «осуществляется»;
- одна мысль - одно предложение, повтор мысли другими словами запрещён;
- в основном тексте только дефис, без длинных тире (тире остаётся там,
  где его требует образец: подписи, библиография, титул).

## Чего пока нет

Эти материалы агент запросит у вас, пока их нет в репозитории:

- [ ] варианты, методичка и образец ДР по электротехнике;
- [ ] методички к лабораторным работам;
- [ ] шаблон и требования к отчёту по практике;
- [ ] правильный титул для статьи (`Title page - Статья.doc` сейчас
      повторяет титул курсовой);
- [ ] список журналов ВАК К1 по направлению;
- [ ] лекции ЭиС 5 и 8, тема 13 по СМК;
- [ ] список литературы по «Трансформации производственных процессов».

Ещё одна деталь: в титуле курсовой указан «Институт радиоэлектроники и
индустриального программирования», а в методичке СиМ и в бланке
задания «Институт перспективных технологий и индустриального
программирования». Название нужно уточнить и исправить в шаблоне.

## Как добавлять материалы

1. **Новая дисциплина.** Создайте папку `<Название RU> - <Name EN>/` с
   подпапками `Lecture materials - Лекционные материалы/` и
   `Recommended bibliography - Приорететные источники/`. Добавьте
   подраздел в §3.3 гайда.
2. **Новая методичка.** Положите её в папку дисциплины, добавьте строку
   в §3 и уберите соответствующий пункт из §12.
3. **Новый титул.** Положите его в `Title page - титульный лист/` и
   обновите таблицу в §6.
4. **Правила преподавателя.** Создайте в папке дисциплины файл
   `Rules - <описание>.md` и сошлитесь на него в §3 и §7.
5. **Проверка.** После правки убедитесь, что все пути в гайде совпадают
   с реальными именами файлов, а в тексте гайда нет длинных тире
   (чек-лист в §11).

Старые форматы `.doc` по возможности пересохраняйте в `.docx`: так
нейросетям проще их читать.

## Ответственность и лицензия

- Репозиторий предназначен для личного использования при обучении.
  Ответственность за итоговую работу несёт студент: проверяйте расчёты,
  источники и оформление перед сдачей.
- Методические материалы и лекции принадлежат РТУ МИРЭА и их авторам.
  Не распространяйте их публично без проверки авторских прав.
