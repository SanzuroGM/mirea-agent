# mirea-agent

Единый гид для ИИ-агента (LMArena и аналоги), выполняющего учебные
работы студента РТУ МИРЭА. Один `.md`-файл, который кидаешь в чат,
плюс папка с методичками, титульниками и требованиями кафедры.

## Что это

`AGENT_GUIDE.md` - мастер-файл. Внутри:

- классификатор задач (ДР, лаба, практика, курсовая, тетрадь);
- протоколы под каждый тип работы;
- стилевые правила (анти-ИИ, научный стиль);
- шаблоны титульных листов;
- pipeline работы агента (сбор данных, черновик, валидация, финал);
- требования кафедры и список ВАК К1.

`attachments/` - исходники: методички, варианты, образцы, титульники.

## Как пользоваться

1. Открыть `AGENT_GUIDE.md`.
2. Скопировать его целиком в чат LMArena (или другой ИИ).
3. Написать запрос, например:

   > Сделай ДР 1 по электротехнике, вариант 54.

4. Агент сам:
   - определит тип задачи;
   - запросит ФИО, группу, преподавателя для титульника;
   - возьмёт методичку из `attachments/`;
   - рассчитает по протоколу;
   - оформит по ГОСТ и §0.5;
   - проверит текст по чек-листу.

## Требования к тексту (кратко)

- Научный стиль, без воды и оценочных суждений.
- Длинные тире запрещены, только дефис.
- Конструкция «1+1» (повтор одной мысли дважды) запрещена.
- Источники не старше 5 лет, DOI обязателен.
- Никаких выдуманных авторов, статей и годов.
- Список литературы - по ГОСТ Р 7.0.5-2008.

## Как обновлять

1. Правки в стиль и протоколы - только через `AGENT_GUIDE.md`.
2. Новые методички - в `attachments/<предмет>/`.
3. Новые требования кафедры - в `attachments/kafedra/trebovaniya.md`.
4. После каждой правки - прогнать `AGENT_GUIDE.md` через
   чек-лист §0.5 (в §9 это шаг 0).
